# 🌸 Spray 21 – Perfume Shop Web Application

## 📌 Overview

Spray 21 is a web-based perfume shop application developed using the Laravel framework. The project simulates a simple e-commerce platform where users can browse perfume products, view detailed information, and interact with a clean and user-friendly interface. It is designed to demonstrate practical knowledge of web development, including backend logic, database integration, and MVC architecture.

---

## 🚀 Features

* Browse perfume products
* View product details
* Add items to cart
* Simple and responsive UI

---

## 🛠️ Technologies

* PHP (Laravel)
* HTML, CSS, JavaScript
* MySQL

---

## ⚙️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/spray21.git
cd spray21
```

2. Install dependencies

```bash
composer install
```

3. Setup environment

```bash
cp .env.example .env
```

4. Configure database in `.env`

5. Generate key

```bash
php artisan key:generate
```

6. Run migrations

```bash
php artisan migrate
```

7. Start server

```bash
php artisan serve
```

Open: http://127.0.0.1:8000

---

## 📖 Notes

Make sure PHP, Composer, and MySQL are installed. Create a database before running migrations.
